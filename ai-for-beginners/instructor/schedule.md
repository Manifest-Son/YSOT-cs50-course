# Schedule (6 sessions, 90 minutes each)

Cohort: 24 students (12 pairs). Adjust timings as needed.

## Session 1 - Why AI? (90 min)
- 0:00-0:10 Predict before you run
- 0:10-0:30 Rules vs search vs learning (slides + discussion)
- 0:30-0:70 Pair work: breakout.py + session1_rules starter
- 0:70-0:85 Explain it back
- 0:85-0:90 Wrap-up

## Session 2 - Search (90 min)
- Minimax, position counter, never-lose proof.

## Session 3 - Learning (90 min)
- Bandit explore/exploit; Q-learning trains against minimax.

## Session 4 - Generative AI (90 min)
- LLMs, prompts, hallucination hunt worksheet.

## Session 5 - Showcase (90 min)
- Tournament + demos.

## Session 6 - Peer-to-peer coding (90 min)
- Pairs extend capstone; instructor roams.
