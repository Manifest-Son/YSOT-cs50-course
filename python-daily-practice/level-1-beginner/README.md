# Level 1: Beginner, Mavuno School edition (35 days)

**Theme:** every challenge is about running **Mavuno School**. By Day 35 you will have built a working **Mini School Management System** from your own pieces. (The school and its rules are described in [DOMAIN.md](../DOMAIN.md).)

**How it works:** one day at a time. Early days teach a single topic, some days merge topics you already know, and the project days put everything so far together. Spend 30 to 60 minutes a day. Each day has its own folder with a `README.md` that explains the assignment and how to do it, and starter code for you to continue.

Later days build on earlier ones. When a day says "reuse your Day N code", copy your finished work from that day into the new day's starter file and carry on.

**Day types:** **Topic** = one new idea · **Merge** = combine ideas you already know · **Project** = a bigger piece of the school system.

## Capstone checklist

Your final project should use **every Level 1 concept**:

- [ ] Variables, operators and data types
- [ ] `input()` and formatted `print()` output
- [ ] String cleaning and f-strings
- [ ] `if` / `elif` / `else` with logical operators
- [ ] `for` and `while` loops with `break` / `continue`
- [ ] Lists, tuples, sets and dictionaries
- [ ] Functions with parameters and return values
- [ ] Error-free, readable code with comments
